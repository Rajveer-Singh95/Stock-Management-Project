# StockFlow - Smart Inventory & Supply Chain Management

![StockFlow Banner](https://via.placeholder.com/1200x400/020617/6366f1?text=StockFlow+-+Smart+Inventory+System)

An end-to-end inventory and supply chain tracking solution built with modern web technologies. This application allows businesses to manage stock levels, track purchase orders, forecast demand, and receive automated alerts for low stock.

## 🚀 Features

*   **Real-time Dashboard:** Track total products, low stock alerts, active orders, and monthly revenue.
*   **Inventory Management:** View, search, and adjust stock levels with detailed product information.
*   **Supplier Directory:** Manage supplier contact information, lead times, and performance ratings.
*   **Purchase Orders:** Track the lifecycle of purchase orders from pending to received.
*   **Automated Alerts:** A cron-based background service that monitors stock thresholds and generates alerts.
*   **Demand Forecasting:** Analytical reports projecting inventory needs and valuations.
*   **Secure Authentication:** JWT-based login system.

**Frontend:**

## 💻 Getting Started

### Prerequisites

*   Node.js (v18 or higher)
*   A [Neon.tech](https://neon.tech/) PostgreSQL Database
*   An [Upstash](https://upstash.com/) Redis Database

### 1. Clone the repository
```bash
git clone https://github.com/Rajveer-Singh95/Stock-Management-Project.git
cd Stock-Management-Project
```

### 2. Backend Setup
Navigate to the backend directory:
```bash
cd backend
npm install
```

Create a `.env` file in the `backend` directory and add your connection strings:
```env
DATABASE_URL=postgresql://user:password@endpoint.neon.tech/neondb?sslmode=require
REDIS_URL=rediss://default:password@endpoint.upstash.io:6379
JWT_SECRET=super_secret_jwt_key_12345
JWT_EXPIRES_IN=7d
```

Run the database seeder to initialize tables and insert demo data:
```bash
npm run seed
```

Start the backend development server:
```bash
npm run dev
```
*(The backend will run on `http://localhost:5000`)*

### 3. Frontend Setup
Open a new terminal window and navigate to the frontend directory:
```bash
cd frontend
npm install
```

Start the frontend development server:
```bash
npm run dev
```
*(The frontend will run on `http://localhost:3000`)*

### 4. Login
Navigate to `http://localhost:3000` in your browser. 
You can log in using the demo admin credentials generated by the seed script:
*   **Email:** `admin@inventory.com`
*   **Password:** `admin123`
